# DEC-001

Data: 29/07/2026

Título:
Perfil Nutricional baseado em evidências.

Decisão:

Todos os perfis nutricionais do Calc-Grower Pro deverão possuir justificativa técnica documentada.

Motivo:

Garantir rastreabilidade e evolução contínua.

Impacto:

Todos os módulos utilizarão apenas perfis documentados.
